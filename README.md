## 📊 Overview

Advanced 3D terrain visualization system for mineral distribution analysis across the Indian subcontinent. Features cinematic rendering, real-time rotation, and interactive exploration.

## ✨ Features

- **Ultra HD Cinematic Rendering** - Neon gradient terrain with glass-like effects
- **360° Auto-Rotation** - Smooth animated camera movement
- **Interactive Controls** - Mouse-based zoom, pan, and rotate
- **Realistic Geography** - Accurate Himalayan peaks and Deccan Plateau
- **Mineral Markers** - Glowing holographic deposit indicators
- **Multiple Themes** - Cinematic, realistic, minimal, and dark modes

## 🎯 Mineral Deposits Tracked

- ⚫ Coal (Jharkhand, Chhattisgarh, Odisha)
- 🔴 Iron Ore (Karnataka, Odisha, Goa)
- 🟠 Bauxite (Chhattisgarh, Odisha)
- 🟤 Copper (Rajasthan, Madhya Pradesh)
- 🟡 Gold (Karnataka, Bihar)
- 🟣 Manganese (Maharashtra, Karnataka)

## 🚀 Quick Start

```bash
# Install dependencies
pip install numpy matplotlib scipy

# Run cinematic visualization
python cinematic_terrain_ultra.py

# Run rotating animation
python rotating_terrain_visualization.py

# Switch terrain models
python terrain_model_switcher.py
```

## 🎨 Visualization Modes

### Cinematic Mode
- Neon gradients (cyan → magenta → yellow → green)
- Dark cyber background
- Glass base platform
- Transparent grid overlay

### Rotating Mode
- Automatic 360° camera rotation
- Real-time mouse interaction
- Smooth animation loop
- Presentation-ready output

### Standard Mode
- Realistic terrain colors
- High-contrast mineral markers
- Clean scientific aesthetic

## 🛠️ Technical Specifications

- **Resolution:** 300x300 to 500x500 mesh grid
- **Output:** Ultra HD PNG (300-400 DPI)
- **Rendering:** Gaussian-filtered smooth surfaces
- **Lighting:** Ambient shading with antialiasing
- **Performance:** Optimized for real-time interaction
