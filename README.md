# Mineral-Exploration

A 3D visualization project for mineral exploration and terrain analysis.

## Features
- 3D terrain visualization
- Advanced mineral deposit mapping
- Interactive 3D plots
- Multiple visualization modes

## Files
- `terrain_3d.py` - Basic 3D terrain visualization
- `visualize_3d.py` - Standard 3D visualization
- `visualize_3d_simple.py` - Simplified 3D viewer
- `visualize_3d_advanced.py` - Advanced visualization with multiple features
- `Mineral.ipynb` - Jupyter notebook for analysis

## Usage
Run any of the Python scripts to generate 3D visualizations of mineral exploration data.
